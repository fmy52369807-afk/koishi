# 匿名演示夹具

本目录只包含为公开演示而写的虚构样例，不来自任何真实 QQ 群、私聊、提醒、用户画像、语音、图片或向量库。

- `fixtures/conversation.json`：文字对话、RAG、联网搜索和多模态上下文的匿名输入输出。
- `fixtures/assistant-state.json`：提醒、待办和长期记忆的匿名持久化样例。
- `fixtures/plugin-map.json`：可用于截图、幻灯片或面试讲解的插件装配清单。

演示时请运行本地空数据库或这些夹具；不要截取 `data/koishi2.db`、`data/library/`、聊天记录、真实群号、账号 ID、图片 URL、音频或 `.env`。
